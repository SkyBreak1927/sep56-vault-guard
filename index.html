Aegis Vault

An open-source checker for SEP-56 tokenized vaults on Stellar. Point it at a Soroban vault contract and it runs 11 conformance and security checks — the same ones shown above — and tells you exactly what passes and what doesn't.

// how it works

What it checks

Seven checks confirm the vault behaves the way SEP-56 requires — deposits, withdrawals, and share math all matching what the contract itself previews. Four more probe it the way an attacker would: donation attacks, overflow, rounding direction, and access control.

How a check runs

Positive checks call your vault directly. Security checks deploy a disposable clone with the same code and parameters first, then attack the clone — your vault's live state is never touched.
